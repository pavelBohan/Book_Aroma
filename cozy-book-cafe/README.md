# 📖☕ Книжный аромат: История одного кафе

Уютный симулятор управления книжным кафе в эстетике **Dark Academia** — упрощённая игра «по типу Papa Louie», но в другом стиле: вместо бега по ресторану — подготовка, диалоги и развитие кафе.

## Запуск

Простой статичный HTML/JS-проект (без сборки и зависимостей):

```bash
cd cozy-book-cafe
python3 -m http.server 8080
# откройте http://localhost:8080
```

Или просто откройте `index.html` в браузере.

## Как играть

История делится на **5 глав (дней)**. Каждый день — три фазы:

| Фаза | Что происходит |
|---|---|
| ☀️ **Утро** | Мини-игра помола зёрен (лови бегунок в зелёной зоне), выбор напитка, способа заваривания (воронка / эспрессо-машина / френч-пресс), температуры, выпечки и **книги дня** на витрину |
| 🌤️ **День** | Приходят гости-персонажи (писатель в шляпе, художник, девушка с кошкой…) и просят настроение: *«горькое, но с надеждой»*. Соберите поднос **напиток + десерт + книга** так, чтобы их теги-«Ароматы» совпали с запросом. Следите за шкалой Уюта |
| 🌙 **Вечер** | Трата зёрен: стеллажи, лампы-чашки, грамофон, портреты классиков, новые книги, **мерч** (пассивный доход). Проведение ивентов: поэтический вечер, книжный клуб, дегустация эспрессо |

### Ключевые системы
- **«Ароматы»** — теги Терпкий / Философский / Романтичный / Детективный / Бодрящий / Уютный / Мистический / Сладкий у напитков, десертов и книг. Идеальная пара = все теги гостя покрыты + правильная обложка + качество ≥ 70%.
- **Книга дня приманивает «своих» гостей** (поэзия → поэты, детектив → инспектора).
- **Древо литературы**: покупка книг открывает новых гостей, рецепты и диалог-ветки. Писатель в подарок отдаёт редкий том «Мастера и Маргариты».
- **Валюты**: 🫘 Зёрна (основная) и ⭐ Рецензии (премиум, за идеальные заказы и ивенты).
- **8 достижений** («Русская классика», «Хранитель уюта», «Кофейное состояние»…).
- Автосохранение в `localStorage` — кнопка «Начать чтение» продолжит с той же фазы.

## Структура

```
cozy-book-cafe/
├── index.html        — разметка: меню, HUD, сцена кафе, панель действий
├── css/style.css     — палитра: оливковый, древесный, кремовый, кофейный
├── js/data.js        — книги, напитки, десерты, гости, магазин, ивенты, ачивки
├── js/game.js        — core loop: утро → день → вечер, мини-игры, сохранение
└── assets/logo.svg   — чашка с паром-книгой (иконка)
```

## Пример квеста из концепт-дока (реализован)

> 🕵️ Писатель в шляпе: *«Что-то горькое, но с надеждой. И обязательно книга в твёрдой обложке.»*
> Решение: двойной эспрессо (терпкий+бодрящий) + капкейк с черникой (мистический) + «Мастер и Маргарита» (тв. обложка) → большие чаевые + редкая книга в подарок.
